# Программа №1

Двухпоточное приложение для обработки числовых строк с отправкой результатов по TCP.

## Функционал

- **Поток 1**: принимает ввод пользователя, валидирует (только цифры, ≤64 символа), сортирует по убыванию, заменяет чётные цифры
- **Поток 2**: получает данные из общего буфера, вычисляет сумму цифр, отправляет результат в Программу №2
